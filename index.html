💡 経済的な着眼点: 近年、国内の生産活動を示す「GDP」に対して、国民や国内企業が海外から得る投資収益（配当や利子）を含めた「GNI」が大きく上回っています（年間約40兆円以上の受取超過）。日本経済が「貿易立国」から「投資立国」へ構造変化した姿が国民所得の推移からも鮮明に読み取れます。

⚡ uv によるワンライナー実行

このプロジェクトは PEP 723 (Inline script metadata) を採用しているため、仮想環境の作成や pip install なしで即座に実行可能です。

# リポジトリをクローンして即実行
uv run visualize_national_income.py

📜 PEP 723 メタデータ定義

スクリプト冒頭に依存関係を宣言しており、Python 3.10〜3.14 環境で自動解決されます。
