「名目」と「実質」の読み解き方

【名目（Nominal）】 その年の市場価格で計算した額面上の数値。インフレ（物価上昇）局面では金額が大きく膨らみます。
【実質（Real）】 基準年価格で固定し物価変動の影響を除去した数値。国民の実質的な購買力や生活水準を表します。

※ 2022年以降はインフレ影響により「名目GNI」が700兆円規模へ急拡大する一方、「実質GNI」は約608兆円で推移しており、名目と実質の乖離（物価上昇要因）が鮮明になっています。

⚡ uv によるワンライナー実行

このプロジェクトは PEP 723 (Inline script metadata) を採用しているため、仮想環境の作成や pip install なしで即座に実行可能です。

# リポジトリをクローンして即実行（名目・実質データを最新化）
uv run visualize_national_income.py
